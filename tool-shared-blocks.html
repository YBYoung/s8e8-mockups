What this mockup decides (#1291, spec #1289)

  • One input block for every tool: pick a client (fills domain, address, listing from the record) or type it. Red asterisk marks what the tool needs.
  • The estimate sits on the Run button and in the row, before every fire. Disabled until the inputs are complete.
  • History is listed by domain, newest first. Prospects show with no client; a run can be linked to a client from the row. "Clients only" hides prospect runs.
  • Deep teal primary, white cards, grey uppercase labels, rounded corners, no pills, no colored edges.
