What's built into this mockup

  • Time echo (the request): hover any week and a dotted line runs back to the last time the pile sat at that number, with the date and how long ago. The caption says it in words, including direction: "climbing then; coming down now." All-time highs say so instead.
  • Echo on the projections (the vice versa): hover the teal dashed line and it answers "back to February levels by November." The red dashed line sits above anything on record, and says so.
  • Click to pin: click a week to hold its echo on screen while you talk or screenshot; click it again, or press Esc, to release. Hover keeps working on top of a pin.
  • Bars and line talk to each other: hover a month bar to shade that month on the line; hover the line to flag that week's month bar.
  • Draw-in intro: the line sweeps in, then the projections fade up. Honors reduced-motion. Replay button up top.
  • Smarter default caption: before any hover, the caption already names the echo for the current level ("a level last seen in mid-May").

Worth considering, not built here

  • Arrow keys to walk the line week by week. Points are focusable (Tab works, echo included); arrows would make the keyboard path fast.
  • Shift-hover for "one year ago": a second comparison mode that matches the same week last year instead of the same level, for seasonality questions.
  • Echo in the weekly exec email: the same sentence travels well as text: "371 overdue, last seen mid-May."
