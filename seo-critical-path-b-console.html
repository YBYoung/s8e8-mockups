Reading the console: module color is the category's existing grade, nothing is recalculated. A breached module pulses red and its feeds go hot; everything downstream switches to a dashed jeopardy border, meaning its supply line is failing even if its own numbers hold. Migrations sits on an optional bypass between Onboarding and Strategy: skipping it is normally fine, the dev team increasingly handles migrations themselves, so a stall there never puts the main path in jeopardy. Support runs as an independent system, off the path entirely. Hover any module for its numbers; clicking opens the Task Hub filtered to that category.
