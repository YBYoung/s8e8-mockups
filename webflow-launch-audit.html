How confidence is scored

  • 95% API DATAItem counts and publish states read straight from the Webflow CMS API. Essentially certain.
  • 85% PAGE PROBEHub pages checked by requesting the live URLs (/services, /dental-services, /blog, /articles, and variants). A site using an unusual slug would read as "missing" when it is not.
  • 70% NAV CHECKRead from the published homepage's nav HTML. A dropdown menu built with JavaScript can hide a link from this check, so "not in nav" findings deserve a quick eyeball before acting.

04How this was checked, and where it can be wrong

  1. CMS collections: listed via the Webflow API for every site; item counts, draft flags, and publish states are exact.
  2. Hub pages: probed on the live/staging site over HTTP against common slugs (services, service, our-services, dental-services; blog, articles, posts, resources). A 200 response counts as live.
  3. Navigation: fetched each published homepage and parsed the nav element for links to the hub slugs.
  4. Recency: Webflow has no "first published" date, so "went live in the past 3 months" is approximated as "site created in the last 100 days and currently published." A site built earlier but launched recently would be missed; cross-referencing CRM launch dates would close that gap.

Two known blind spots: the API token lacks the pages:read scope, so hub-page existence relies on the HTTP probes above rather than the authoritative page list; and JavaScript-rendered dropdown menus can hide nav links from the parser, which is why nav findings cap at 70% confidence. The two verification items (Washington Center, Wildflower's nav target) are exactly the places where those blind spots could flip the verdict.
