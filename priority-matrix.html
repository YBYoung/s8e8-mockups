How prioritization actually works now

The old matrix was one hand-set table. Today priority is computed from two independent rankings, and this page crosses them for a familiar at-a-glance view.

Axis 1 — task-type tier (SEO Dashboard)

Every tracked project carries a criticality tier in seo_dashboard_registry.py: T1 foundational (Strategy, Migrations, Calendar) down to T4 lower-stakes queues. In the Focus List the tier is the outer sort: a T1 task always outranks a T3 task, no matter how overdue the T3 is. Within a tier, tasks sort by severity (how far past due or past its stuck threshold).

Axis 2 — client package tier (Capacity Desk)

Each client's Asana "Service Package" maps to a rank in capacity_priority.py: MRKT Leader (0) → Performance (1) → Essential (2) → Web Support (3). A client with a missing or unknown package falls to the bottom of the order with a needs package flag. This order shapes Capacity Desk advice, never math.

Overrides the matrix can't show

  • Pins & nudges: a pinned client jumps to the front of the priority order regardless of package; a nudge bumps a client up within it.
  • Promise escalation: any request that endangers a pinned or higher-tier client's promised date escalates automatically, whatever its own cell says.
  • Deadlines: a blown due date always lands in the Past-Due band above everything merely stalled.

What changed since the old screenshot

Rows (task types)

  • AM Requests → nearest tracked equivalent is SEO Support Cases, now a T4 queue. Biggest single change: the old matrix had it Top/High everywhere.
  • Post-Audit Issues → no longer a tracked dashboard project; audit-issue tasks live in per-client projects and only count when multi-homed into a registry project.
  • New rows: Service Pages (T2) and Listing Reviews (T4) are tracked now.
  • Renames: Onboarding Tasks → SEO Onboarding, SEO Migration → SEO Migrations.

Columns (packages)

  • Market Leader → MRKT Leader, Support → Web Support (live Asana values).

Cell labels are derived

The code ranks the two axes but never writes "Top Priority" into a cell. Labels here come from tier + package rank banded into five levels, and N/A cells are carried over from the old matrix's package scopes (the code doesn't encode which packages include which work).
